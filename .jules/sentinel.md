## 2026-07-27 - Command Injection in Vertex Setup
**Vulnerability:** Command injection vulnerability via `GOOGLE_APPLICATION_CREDENTIALS` environment variable (which dictates `saKeyPath`) when fetching a Google Cloud access token. The path was directly embedded into a shell command using string interpolation without sanitization: `execSync(\`gcloud ... $(python3 -c "import json; print(json.load(open('${saKeyPath}'))['client_email'])")\`)`.
**Learning:** Even internal environment variables that specify file paths (like `GOOGLE_APPLICATION_CREDENTIALS`) can be malicious if controlled by an attacker or set to unexpected values containing shell metacharacters. Using `execSync` with strings and `$()` for command substitution is highly vulnerable to command injection. Using `JSON.stringify()` is not a safe mechanism to sanitize input for shell execution either.
**Prevention:** Always use `execFileSync` (or `spawnSync`) with a properly separated array of arguments. To extract data from files (like JSON), parse the file natively in Node.js (e.g., using `fs.readFileSync` and `JSON.parse`) rather than shelling out to external tools (like python) to parse it within the shell command.
