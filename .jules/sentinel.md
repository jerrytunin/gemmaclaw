## 2024-05-15 - Command Injection Vulnerabilities in `execSync`
**Vulnerability:** Numerous instances of `execSync` use string interpolation (e.g., `execSync(\`gh pr create ... --body "\${prBody.replace(/"/g, '\\"')}"\`)\`). This creates command injection vulnerabilities if the interpolated strings contain shell metacharacters or backticks, as they are evaluated by the shell.
**Learning:** `execSync` evaluates commands within a shell by default, meaning dynamically constructed string commands are inherently unsafe. Node.js's documentation strictly recommends using `execFileSync` or `spawnSync` with an array of arguments, as they pass arguments directly to the executable without shell processing.
**Prevention:** Always use `execFileSync` (or `spawnSync` with strict status checks) instead of `execSync`. Separate the executable name from its arguments into an array (e.g., `execFileSync("gh", ["pr", "create", ...])`). Never construct shell commands via string concatenation or interpolation when dealing with dynamic input.
