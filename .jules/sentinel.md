## 2024-07-07 - Command Injection via JSON.stringify in Shell Commands
**Vulnerability:** A critical command injection vulnerability existed where `JSON.stringify()` was used to "sanitize" inputs before interpolating them into a shell command string executed via `execSync`. Specifically, `gh pr create` commands used string concatenation with user-provided or dynamic branch/title inputs wrapped in `JSON.stringify()`.
**Learning:** `JSON.stringify()` outputs double-quoted strings in bash. In Unix shells, double quotes do NOT prevent command substitution (e.g., `$(...)` or `` `...` ``) or variable expansion (e.g., `$VAR`). Thus, an attacker can still execute arbitrary commands even when the payload is stringified.
**Prevention:** Never use string interpolation or `JSON.stringify()` to construct shell commands containing dynamic data. Always use `execFileSync` or `spawnSync` with explicitly separate arguments in an array format (e.g., `execFileSync("gh", ["pr", "create", ...])`).
