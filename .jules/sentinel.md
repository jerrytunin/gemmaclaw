## 2024-05-24 - [CRITICAL] Command Injection in `vertex-setup.ts` via string interpolation
**Vulnerability:** Command Injection vulnerability exists in `src/gemmaclaw/provision/vertex-setup.ts` where `execSync` is called with shell string interpolation using `saKeyPath` (which comes from `process.env.GOOGLE_APPLICATION_CREDENTIALS`).
**Learning:** Using `$(...)` and shell interpolation in `execSync` is highly insecure, particularly when user-controllable input like environment variables are used. The input can contain malicious shell metacharacters resulting in arbitrary command execution. Node.js `fs.readFileSync` and `JSON.parse` should be used to parse JSON before passing clean values via `execFileSync` to avoid any shell interaction entirely.
**Prevention:** Always use `execFileSync` (or `spawnSync`) with a separated arguments array rather than `execSync` with a command string. For extracting values from files to pass to tools, prefer reading and parsing the file securely in Node.js instead of using inline python/shell subcommands.
