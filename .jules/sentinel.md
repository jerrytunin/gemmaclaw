## 2025-05-18 - Command Injection in execSync via String Interpolation
**Vulnerability:** The `submit-benchmark.ts` command used `execSync` with string interpolation for external inputs (e.g., `prTitle` derived from model names in benchmark results, or file paths). Even with `JSON.stringify`, if the payload gets evaluated by a shell (which `execSync` does by default), command substitution via `$(...)` or backticks `` `...` `` inside the string is executed.
**Learning:** `JSON.stringify` does not sanitize shell metacharacters like `$()` or backticks when used inside an interpolated string passed to `execSync` or `exec`. Any external input, especially from potentially malicious sources like model configurations, can lead to arbitrary command execution on the host machine.
**Prevention:** Always prefer executing external commands (like `gh`, `git`, or `docker`) using `spawnSync` or `execFileSync` with an array of arguments instead of `execSync` with string interpolation. This avoids shell evaluation completely.
