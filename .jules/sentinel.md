## 2024-06-01 - Command Injection in Upload Scripts
**Vulnerability:** Command injection vulnerability identified in `src/commands/submit-benchmark.ts` and `src/gemmaclaw/benchmark-kit/upload.ts`. Several `execSync` calls interpolated user-controlled input and environment variables directly into strings executed by the system shell.
**Learning:** This codebase had patterns of using `execSync` for GitHub CLI (`gh`) and Git commands to push and upload results. Because they used string interpolation directly into a shell context, this could allow arbitrary command execution if an attacker can manipulate environment variables, the workspace variables, or other injected properties.
**Prevention:** Always use `execFileSync` or `spawnSync` from `node:child_process` when invoking external executables. By passing an array of arguments to the executable, we bypass the system shell, which guarantees arguments are treated solely as arguments and prevents them from being executed as subsequent commands.
