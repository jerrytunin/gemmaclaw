## 2025-05-18 - Prevent Command Injection via execFileSync Migration
**Vulnerability:** Command injection vulnerability in `src/commands/submit-benchmark.ts` and `src/gemmaclaw/benchmark-kit/upload.ts` due to using string interpolation with `execSync` when executing external commands like `gh` and `git` (e.g. `gh pr create`, `git add`). Unsanitized variables like branch names and titles were passed directly in the string.
**Learning:** `execSync` passes strings directly to a shell which will evaluate any special characters, spaces, or nested substitutions. Double-quoting string variables (`"${variable}"`) or attempting JSON.stringify is not a safe mechanism against execution and variable interpolation if the string contains backticks or `$(...)`. Node.js provides `execFileSync` and `spawnSync` as safer alternatives. Migration to `execFileSync` requires separating the executable name from its arguments (e.g., `execFileSync('git', ['add', file])`).
**Prevention:** Strictly enforce using `execFileSync` or `spawnSync` with an array of arguments, never `execSync` with string interpolation for external tools or commands constructed from variables.
