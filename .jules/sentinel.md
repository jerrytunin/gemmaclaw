## 2024-05-15 - Command Injection via execSync with Shell Interpolation
**Vulnerability:** In `src/gemmaclaw/benchmark-kit/upload.ts` and `src/commands/submit-benchmark.ts`, there are uses of `execSync` combined with shell string interpolation (using `${...}`) for executing GitHub CLI commands (like `gh pr create ...`). These commands construct their arguments directly from external data, such as benchmark result properties, without proper sanitization, creating a Command Injection vulnerability.
**Learning:** Node.js `execSync` delegates command execution to the system shell (e.g. `/bin/sh`), meaning shell metacharacters inside interpolated variables are evaluated. Although some attempts like `.replace(/"/g, '\\"')` were made, they are insufficient to prevent arbitrary command execution.
**Prevention:** Always use `execFileSync` (or `spawnSync` if needed) instead of `execSync`, and pass the executable and its arguments strictly as separate items in an array. This circumvents the shell completely, ensuring variables are always treated as literals rather than evaluated commands. Never rely on manual escaping functions or JSON stringification for shell command substitution.
