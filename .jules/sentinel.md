## 2026-06-06 - Command Injection via Environment Variable
**Vulnerability:** A command injection vulnerability was discovered in `src/gemmaclaw/provision/vertex-setup.ts`. The script passed the value of the `GOOGLE_APPLICATION_CREDENTIALS` environment variable (using string interpolation) directly into a subshell embedded inside an `execSync` command (specifically: `gcloud auth print-access-token --impersonate-service-account=$(python3 -c "import json; print(json.load(open('${saKeyPath}'))['client_email'])")`). If a malicious or untrusted input was provided for `GOOGLE_APPLICATION_CREDENTIALS`, an attacker could inject shell commands.
**Learning:** Environment variables and file paths must not be trusted implicitly. Embedding them via string interpolation into a shell command using `execSync` easily allows command injection.
**Prevention:** Always use `execFileSync` (or similar tools like `spawnSync`) which executes an executable file directly with an array of arguments, bypassing the shell. Also avoid chaining tools like `python3` inside the command and instead perform the equivalent logic (e.g. JSON parsing) securely within the node.js runtime.
