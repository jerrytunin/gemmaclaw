## 2024-06-11 - Command Injection via execSync
**Vulnerability:** A command injection vulnerability was found in `src/gemmaclaw/provision/vertex-setup.ts`. The code was reading a JSON file using `python3 -c "import json..."` inside an `execSync` shell command, where the filename path (`saKeyPath` from the `GOOGLE_APPLICATION_CREDENTIALS` environment variable) was directly interpolated into the string. This allowed execution of arbitrary commands if an attacker could control the environment variable.
**Learning:** Avoid using `execSync` with string interpolation for shell commands, especially when incorporating unsanitized input originating from the environment or users.
**Prevention:** Always prefer using `execFileSync` or `spawnSync` with an array of arguments, which bypasses the shell and prevents command injection. In this specific case, the JSON file could be read directly using Node.js `fs.readFileSync` and `JSON.parse` instead of relying on an external Python process.
