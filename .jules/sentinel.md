## 2025-02-23 - Prevent Command Injection in GCloud Auth via Service Accounts
**Vulnerability:** Service account credential files read from the environment (`GOOGLE_APPLICATION_CREDENTIALS`) were unsafely injected into a `python3` command string and executed via `execSync(..., { shell: true })` implicit shell expansion on UNIX platforms. If a malicious user controls the environment variable, they could have achieved arbitrary code execution.
**Learning:** `execSync` is fundamentally insecure for executing commands involving dynamic user or environment inputs since it spawns a shell that evaluates characters like `$()` or `;`. Furthermore, migrating blindly to `execFileSync` requires passing `{ shell: process.platform === "win32" }` on Windows when calling CLI wrappers like `gcloud` (which are `.cmd` or `.bat` files under the hood) because `execFileSync` does not invoke a shell by default.
**Prevention:** Avoid passing raw paths directly into inline scripts inside a shell command string. Prefer reading files explicitly using `fs.readFileSync` and native JSON parsing in Node.js. Always execute external tools with `execFileSync` passing arguments as an array rather than interpolating strings with `execSync`. Additionally, handle platform-specific execution caveats like Windows `.cmd` wrappers correctly.
