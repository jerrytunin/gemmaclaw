## 2025-02-24 - [Command Injection] Fix arbitrary execution via `execSync`
**Vulnerability:** In `submit-benchmark.ts` and `benchmark-kit/upload.ts`, shell commands were constructed via string interpolation (e.g., ``execSync(`gh repo fork ${opts.targetRepo} --clone=false`)``) without input sanitization. This allowed attackers to perform arbitrary command execution if variables such as `targetRepo`, `datasetDir`, `branchName`, etc., were maliciously crafted.
**Learning:** Node.js's `execSync` and `exec` invoke commands inside a shell. Direct string interpolation into these calls is inherently unsafe because it treats input as raw shell syntax. Standard regex sanitization and escape attempts are often insufficient to prevent all injection vectors.
**Prevention:** Use safer APIs like `execFileSync` or `spawnSync` from `node:child_process` and provide arguments as elements in an array. This forces Node to launch the executable directly, bypassing the shell syntax parsing and mitigating injection attacks.
