## 2025-02-14 - Replace execSync with execFileSync/spawnSync to prevent command injection
**Vulnerability:** Command Injection. The use of `execSync(command)` allows execution of arbitrary commands if any user-controllable data gets interpolated into the command string without proper escaping. Although `submit-benchmark.ts` passes some arguments into `execSync`, utilizing `execFileSync` or `spawnSync` with explicitly separate argument arrays is a more secure practice because it avoids shell interpolation altogether. Double quotes in shell (`execSync` runs in shell) can evaluate substitutions if they are user-controlled (e.g. `$()`, backticks).
**Learning:** `execSync` is a well-known command injection sink because it delegates to a shell. `execFileSync` is the 1:1 drop-in replacement that avoids this by executing the target binary directly with arguments, throwing on non-zero exit codes.
**Prevention:** Strictly enforce the use of `execFileSync` or `spawnSync` for executing external binaries. Do not use string interpolation or `JSON.stringify()` for shell arguments.
