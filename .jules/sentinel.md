## YYYY-MM-DD - Command Injection Risk in Benchmark Upload
**Vulnerability:** The `src/gemmaclaw/benchmark-kit/upload.ts` module uses `execSync` with string interpolation to run shell commands (`gh`, `git`). This pattern allows for command injection or unexpected shell expansion if parameters like `opts.targetRepo`, `opts.datasetDir`, `branchName`, or `anon.runId` contain shell metacharacters. Even though some strings might seem innocuous or derived internally, interpolating raw values into shell commands is a poor security practice and a persistent vulnerability vector.
**Learning:** `execSync` executes the given command string within a shell environment. Double quotes around interpolated variables do not necessarily prevent shell evaluation of embedded variables, backticks, or `$(...)` subshells.
**Prevention:** Migrate `execSync` calls containing variable data to `execFileSync` (or similar safe execution methods) where arguments are passed as an array. `execFileSync` circumvents shell interpolation and execution, avoiding command injection vulnerabilities.
